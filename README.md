# Robotics Club Tasks

This repository contains basic Arduino tasks completed as part of the robotics club selection process.

## Task 1: LED Blinking
- LED blinks at a fixed interval using delay.

## Task 2: Button Controlled LED
- A push button is used to turn the LED ON and OFF.
- Internal pull-up resistor is used for stable input.

## Task 3: Button Controlled Blinking Speed
- LED blinks continuously.
- Each button press cycles through different blinking speeds.

## Tools Used
- Arduino Uno
- Arduino IDE
- Tinkercad for simulation

## Output
Screenshots of simulations are provided in the screenshots folder.
